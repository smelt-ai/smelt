# 项目仓库与工作集交互

已确认采用项目级仓库列表，不增加第二个「＋」。

## 入口与表单

- 复用项目行现有「＋」选择器，保留会话动作，增加「新建工作集」「管理项目仓库」；右键提供同样入口。
- 项目仓库管理使用独立弹窗，显示名称、实际路径和来源。项目根本身是 Git 仓库时自动加入；用户移除后，管理弹窗不能反复自动加回。
- 添加已有仓库使用现有运行时目录选择器：本机使用系统文件夹选择，远程浏览远程目录。选择后预填可编辑的目录名并预览接入位置。
- 项目内仓库直接绑定；项目外仓库保留原位置，在 `<项目>/repos/<名称>` 建软链接。非 Git 根目录、重复实际路径及目标名称冲突明确拒绝，不覆盖文件。
- 克隆表单填写 Git URL 和目录名，克隆到 `<项目>/repos/<名称>`。显示进行状态，失败保留输入和错误；不在错误反馈中暴露 URL 凭据。
- 新建工作集填写任务名、勾选仓库（初次默认全选），预览分支 `feat/<任务>` 和路径 `worktrees/<任务>/<仓库>`。没有仓库时提供添加入口，不禁用整个入口。

## 安全与所有权

- 运行时负责校验 Git 路径、执行克隆和软链接操作、写 SQLite，客户端仅发单条命令。
- 持久化 Smelt 创建的软链接路径，移除时只移除该链接，且验证仍指向原仓库。不删除源仓库或克隆目录。
- 工作集引用中的仓库不允许移除，显示引用它的任务名。
- 文件系统操作成功、数据库保存失败时，绑定只回滚本次创建的链接；克隆保留完成的目录并明确提示路径，防止丢失文件。
- 根项目是 Git 仓库时允许在其内创建 worktree，并在该仓库的本地 exclude 文件中忽略 Smelt 管理目录，不修改用户 `.gitignore`。
- 所有 IO 在事件处理的后台执行；弹窗 busy 时禁止重复提交或关闭，完成后就地更新；失败保留表单。

## 验证

覆盖外部绑定/软链接所有权、项目内绑定、非法目录与重名、克隆失败、引用保护、根 Git 项目工作集，以及 SQLite 新库和旧库迁移。遵循 AGENTS.md，本轮不自行构建或运行测试，向用户提供验证命令。
