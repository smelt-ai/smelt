配色直接取自桌面 crates/smelt-ui/src/ui_theme.rs 的 DARK 色板（Grok Bot 强调蓝 #1084fe）， 表面层级沿用同一条规则：舞台最暗（#070707），会话列表和卡片往上抬（导航栏 #111111 / 卡片 #181818）—— 不在手机上另起一套视觉。目标形态依据 docs/product-roadmap.md §6：手机是指挥台，不是第二块小终端。
