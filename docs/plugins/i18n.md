# 多语言

Smelt 的界面有英文（`en`）和简体中文（`zh-CN`）。插件的文案放在 `locales/ui.yml`，代码里用 `t()` 取，跟着用户选的语言变。

## 文案文件

```yaml
# locales/ui.yml
_version: 2
title:
  en: "Notes"
  zh-CN: "笔记"
note_count:
  en: "%{count} notes"
  zh-CN: "%{count} 条笔记"
cmd.new_note:
  en: "New Note"
  zh-CN: "新建笔记"
```

- 第一行 `_version: 2` 是格式版本，照抄。
- 每个键下面按语言写一句。两种语言都要写。
- `%{名字}` 是占位，取的时候换成参数。
- 键可以带 `.` 分组，只在这个插件里有效，不用加插件名前缀。

`locales/` 下可以放好几个 `.yml` 文件，合在一起用。`smelt plugin check` 会解析它们，格式错了加载不了。

## 在界面里取

```tsx
import { t } from "smelt/sdk";

<Text class="text-foreground">{t("note_count", { count: notes().length })}</Text>
```

`t(key, params?)` 按当前语言取；当前语言没有这条取英文；英文也没有，给键本身。它是响应式的，用户换了语言，读了 `t()` 的地方自动换字。

## 交给宿主显示的标题

视图、命令、页、布局、菜单项的标题由宿主显示。宿主要能在换语言时自己换字，所以给它整张多语言表，不要给 `t()` 取好的一句：

```ts
import { registerCommands, registerViews, text } from "smelt/sdk";

await registerViews([{ name: "main", title: text("title"), icon: "icons/file.svg" }]);
await registerCommands([{ name: "new-note", title: text("cmd.new_note") }]);
```

`text(key)` 给出 `{ en: "...", "zh-CN": "..." }`。也可以直接写这样一个对象，或者只写一个字符串（那就不跟着语言变）。

> [!NOTE]
> `text()` 不带参数。要带参数的标题（比如带个数），用 `t()` 取好再交，并在 `locale_changed` 后重新登记。

## 当前语言

| 函数 | 说明 |
| --- | --- |
| `locale()` | 当前界面语言，`"en"` 或 `"zh-CN"` |
| `systemLocale()` | 系统语言 |
| `locales()` | App 支持的语言 `{ code, name }[]` |

格式化日期、数字时把 `locale()` 交给 `Intl`。

## 写文案

- 两种语言一起写，别只写一种等以后补。
- 中文用全角标点，中英文之间不加空格。
- 少写字：按钮用动词，标题用名词，不加「请」「您」。
